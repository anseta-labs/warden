# stakeFi Warden

Warden is a transaction validation library for ensuring that transactions generated by integrations with stakeFi services.  It follows zero-trust methodologies while ensuring transaction integrity prior to signing.

stakeFi Warden is built to protect customers from malicious transactions and is built to ensure that all transactions derived from the stakeFi API, SDK's, and other integrations remain untampered from source to broadcast.

Likewise, Warden includes a number of helpful integrations with other stakeFi utilities.

# @bcwresearch/stakefi-warden

TypeScript library for **stakeFi integrators**: validate **unsigned** transactions (e.g. EVM hex) **before** signing, using rules keyed by `chainId` and `TransactionType`.

## Requirements

- Node **20+**
- **pnpm**

## Setup

```bash
pnpm install

pnpm test
```

## Usage

### General Transction Usage

```ts
import {
  Warden,
  TransactionType,
  type ValidationRequest,
} from '@bcwresearch/stakefi-warden';

const warden = new Warden();

const chains = warden.getSupportedChains(); // e.g. [1, 560048]
warden.getSupportedTransactionTypes(chains[0]); // e.g. ['DEPOSIT', 'FORCE_EXIT', 'WITHDRAW']
warden.isSupported(chains[0], TransactionType.DEPOSIT); // true if registered
warden.isSupported(1, TransactionType.WITHDRAW); // EIP-7002 partial withdrawal
warden.isSupported(1, TransactionType.FORCE_EXIT); // EIP-7002 full-exit (0 gwei in calldata)

// Unsigned EIP-1559 (or legacy) tx hex from your API — do not sign before validating
const request: ValidationRequest = {
  unsignedTransaction: '0x02f8...', // RLP-serialized unsigned tx, 0x-prefixed
  userAddress: '0x...',
  chainId: chains[0],
  transactionType: TransactionType.DEPOSIT,
  // args: optional integrator hints; context: optional; Warden merges chainId into context for validators
};

const result = warden.validate(request);
if (result.isValid) {
  // Safe to present to the wallet for signing
  console.log(result.detectedType); // same as request.transactionType when valid
} else {
  // Request validation failed, do not proceed with signing!
  console.error(result.reason, result.details);
}
```

### stakeFi API Usage

```ts
import {
  Warden,
  TransactionType,
  type ValidationRequest,
} from '@bcwresearch/stakefi-warden';

const warden = new Warden();
const chains = warden.getSupportedChains();

// stakeFi Ethereum Staking Transaction creation endpoint
const StakeEthTxEndpoint = "https://preview.api.stakefi.network/v1/ethereum-staking/stake";

const options = {
  method: 'POST',
  headers: {
    'x-api-key': process.env.STAKEFI_API_KEY,
  },
  body: {
    network: "ethereum-mainnet",
    amountWei: "64000000000000000000",
    withdrawalAddress: "0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045",
    feeRecipient: "0x388C818CA8B9251b393131C08a736A67ccB19297",
    validatorName: "my-validator-mainnet-01",
    gasLimit: 36000000
  }
}

const apiResp = await fetch(stakeFiAPIStakeEthURL, options);

// Skipping Fetch Request Checks for Illustration purposes
// in Production, along with standard HTTP request checks, check for 
// apiResp.success checks as well

const { data } = apiResp;

const request: ValidationRequest = {
  unsignedTransaction: data.depositTransaction.encodedTx,
  userAddress: '0x...',
  chainId: chains[0],
  transactionType: TransactionType.DEPOSIT
}

result = warden.validate(request);

if (result.isValid) {
  // Safe to present to the wallet for signing
  console.log(result.detectedType); // same as request.transactionType when valid
} else {
  // Request validation failed, do not proceed with signing!
  console.error(result.reason, result.details);
}
```

## Test fixtures

`EthereumBeaconValidator` tests use **frozen unsigned tx hex** in `__fixtures__/`. That avoids pulling **`@noble/curves`** (ESM BLS used only in `build-eth2-tx`) into Jest, which is easier than ESM-only test runner setup. After changing deposit building logic, run **`pnpm run generate-eth2-fixtures`** and commit the updated JSON.
